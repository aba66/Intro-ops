项目名称

轻量级 GPU 算子运行时与端侧推理算子开发

项目描述

基于 C++/CUDA/Python 构建一个面向模型推理部署的轻量级 GPU 算子运行时，支持通过 Python API 调用底层 C ABI，并实现 copy、vector_add、reduce_sum、softmax、relu 等基础算子。项目覆盖算子 descriptor 生命周期、Tensor 元信息抽象、CUDA stream 传递、动态库加载、正确性测试和 benchmark，对齐端侧部署中低依赖、稳定 ABI、算子级性能优化和端到端调用开销控制等需求。

简历 Bullet

  • 实现面向推理部署的轻量级 GPU Operator Runtime，采用 C ABI 封装算子创建、workspace 查询、执行和销毁流程，支持 Python 层通过 ctypes 调用底层 CUDA 动态库。
  • 设计 TensorView 抽象，封装 dtype、shape、stride、data pointer 等张量元信息，支持上层 PyTorch Tensor 与底层自定义 CUDA kernel 之间的数据传递。
  • 实现 NVIDIA 后端基础算子，包括 copy、vector_add、reduce_sum、softmax、relu，覆盖 FP32/FP16、contiguous tensor、row-wise reduction 等典型推理计算场景。
  • 使用 CUDA grid-stride loop、shared memory reduction、numerically stable softmax 等方式实现基础 kernel，并与 PyTorch baseline 进行正确性和性能对比。
  • 集成 CUTLASS/CuTe，实现向量化 copy kernel，处理对齐访问、尾部边界判断以及 CUDA/CUTLASS 版本兼容问题。
  • 搭建 CMake/Ninja/Conda 构建与验证流程，完成 NVIDIA 后端编译、动态库加载、pytest 正确性测试、benchmark 和 examples 端到端验证。
  • 熟悉模型端侧部署中的算子执行链路，包括低开销 ABI 调用、CUDA stream 管理、workspace 管理、动态库加载、内存布局检查和算子级性能分析。

端侧部署强调版

轻量级 GPU 算子运行时与端侧推理算子开发：基于 C++/CUDA/Python 实现面向推理部署的算子执行框架，通过 C ABI 封装算子生命周期并提供 Python 调用入口；实现 copy、vector_add、reduce_sum、softmax、relu 等基础 CUDA 算子，覆盖 FP32/FP16、contiguous tensor 和 row-wise reduction 场景；使用 shared memory reduction、数值稳定 softmax、CUTLASS/CuTe 向量化 copy 等方式优化 kernel，并通过 pytest、benchmark 和 examples 完成端到端验证。
